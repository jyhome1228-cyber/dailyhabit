# daily.habit.

**Better Habit, Better Life**

Cafe24 이전을 전제로 제작하는 Dailyhabit HTML/CSS/Vanilla JS 프론트엔드 프로토타입입니다.

## Design System

- Desktop content width: **1280px**
- Key color: **Red**
- Primary: `#D92D20`
- Deep Red: `#8F1D18`
- Soft Red: `#F1D5D0`
- Warm White: `#F8F6F2`
- Main text: `#161616`
- Font: Pretendard
- Framework: 없음
